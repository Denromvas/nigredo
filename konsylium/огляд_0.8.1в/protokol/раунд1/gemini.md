## 3. Н — нове на виправленнях

- **`sqlite_sequence`:** Запобіжна відмова стається лише тоді, коли нових рядків для таблиць з `AUTOINCREMENT`, яких ще немає в `sqlite_sequence`, більше, ніж місця до 2⁶³−1. SQLite оновлює наявні рядки на місці. Отримати rowid навмання без урахування лічби або сховати спробу за цим вузьким залишком неможливо.
- **Права без дії (квота, `--сухо`):** Бачать байткод через `EXPLAIN`. Жодної «нетривожної» події, за якою ховається спроба поза правами, не лишається — видається «заборонено».
- **`sqlite_dbpage`:** authorizer дає відмову на будь-яку дію (читання та запис). Інших шляхів до сирих сторінок чи запису повз SQL немає.
- **Звичайна робота:** Перевірено запуск програм у середовищі:
  - Завдання А (мережевий запит, JSON, точні дроби): 3 запуски, успішно (285.60);
  - Завдання Б (XML camt.053, XPath, групування): 1 запуск, успішно;
  - Завдання В (схема `✓`, `∧`, `∨`, `τ`): 1 запуск, успішно (виявлено всі невідповідності).
  Робота йде без хибних відмов, без втрати швидкості, розбіжностей Атанор/еталон чи коду 4.
