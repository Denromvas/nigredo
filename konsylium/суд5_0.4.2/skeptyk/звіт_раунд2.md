У раунді 1 я sha256 не бачив. Тепер побачив, через вміст коміту (пісочниця не пускає `sha256sum` на файли поза текою,
але пускає потік із git):
```
git show c2e160b:interpreter/nigredo.py | sha256sum  → 41d834f1af1ce41ad81657e8475863cfeb7fe6696e6460206ffaee2c0992908b
git show c2e160b:mcp/nigredo_mcp.py    | sha256sum  → 5b95b19549867ca8db8482e427a1ba8ab4a87de1efa3d5e9ba7a8c757c43e176
git status --short ../../../interpreter ../../../mcp → порожньо
```
Робочі файли дорівнюють коміту `c2e160b`, а коміт має саме ці хеші з ПРАВИЛ. Версію заморожено, і це підтверджено.

## Що це змінило

**Виправляю себе.**
1. У раунді 1 я радив власнику: поки Д-1/Д-2 не виправлено, «дивитися код виходу». Для `--перевірити-слід` це
   правильно (там 1 при ✗). **Для `--печатка` — ні:** код 0 і при ✗. Тобто в ключа власника `--печатка` зараз
   немає жодного каналу, якому можна вірити без застережень. Текст програма може дописати (Д-1, рядок 1 таблиці),
   а код виходу нічого не каже. Через MCP так само: `isError` завжди false, а текст іде в LLM-отримувача, тобто це
   готове місце для prompt injection. Опис `nigredo_pechatka` при цьому каже: «цього досить, щоб вирішити».
2. Про впевненість я помилився (див. вище). Аудитор показав, що «впевненість як семантика» має канал завершення,
   а памʼятка обіцяє більше, ніж дає SPEC.

**Що посилилося.** Неправду від `--печатка` троє учасників знайшли **незалежно** (я, Оркестратор, Новачок), і кожен
звичайним `\n` в обмеженні теки. Це не екзотика, а перше, що спробує будь-хто, хто дивиться на звіт як на текст.
Ескалацію субагента теж знайшли незалежно двоє. Тобто «підмножина дозволів для субагента», головна обіцянка
делегування, тримається лише для коду, **написаного** всередині `🜁`, а не для **виконаного** там.

**Що не змінилося і що визнаю прямо.** Межу **дій** не пробив ніхто з семи. Програма ніде не прочитала, не записала
й не звернулася ні до мережі, ні до агента поза своєю печаткою та дозволами власника. Ні `..`, ні посилання, ні
`/proc`, ні підсаджені програми, ні `--дозволи`, ні вкладені субагенти цього не дали. Порахувавши разом, це сотні
спроб. Умову Аудитора з суду 4 в її **ресурсній** частині виконано. За два суди це шлях від «субагент виходить до
`/etc`» до «нічого», і це справжнє досягнення, а не хайп.

## Остаточний голос

**Б — лишається експериментальною.** Близько до А, але не А.

Обґрунтування. Мірило цього суду має дві половини: (1) дія поза печаткою чи дозволами власника; (2) змусити
`--печатка` чи `--перевірити-слід` сказати отримувачу неправду. Першу половину 0.4.2 витримала. Другу порушено,
і запуском, незалежно трьома учасниками. Програма, що «лише читає» за текстом `--печатка` з «✓», записує файл
(`р2_печатка_лише_читає.ngr`). У `--перевірити-слід` програма показує «✓ від P» для сліду Q (мій Д-2). Python не
має печатки взагалі, тож Nigredo уже краща за «Python + обіцянка». Але головна причина мові існувати — **довірений
звіт про права**. Поки цей звіт пише частково сама програма, рекомендувати її як **спільну** мову, де отримувач
вирішує за `--печатка`, я не можу. Це саме те, що суд мав перевірити.

Усе знайдене виправляється малими змінами. Тому умови для «А» конкретні, і нового повного суду вони не потребують:
1. `safe()` (або заборона на розборі) для всіх полів `--печатка`, `--розбір`, «бракує» і поля «програма» у
   `--перевірити-слід`; негативні тести на `\n`, ESC, bidi, NUL **у кожному полі**; NUL/помилки ОС — звичайна
   `NgrError` зі слідом, без трасування.
2. `--печатка` → ненульовий код при ✗; MCP `isError` за змістом; опис `nigredo_pechatka` — «необхідно, не досить».
   Бажано `--печатка --json` для агентів-отримувачів.
3. `delegate()`: права `🜁` під час виконання = перетин із правами агента, що його виконує (тест на `р2_ескалація.ngr`).
4. Канал завершення: після сумнівної `🜍`/`☠`/зупинки решта запуску не впевненіша за неї; або чесно прибрати обіцянку
   з памʼятки. Впевненість — у записі «вивід».
5. Слід: друк після запису «вивід» (або однакове кодування), перевірка неперервності `№`, «заборонено» для шляхів
   поза текою, у підсумку перевірки — тека, аргументи, зерно (мій Д-3).
6. Короткий повторний огляд **замороженої** версії з цими виправленнями: усі `р2_*.ngr` і `атака5_*.ngr` учасників
   мають дати видиму відмову. Якщо це так, мій голос — **А** для ніші «печатка + слід», без претензії на мову
   загального призначення.
