## 3. Н — нове

**`--звірити` (тримає):**
- **у сховище нічого не кладе.** Модуль `c0ffee…07` звірено ✓, але файлу `08eaf56f…` у сховищі немає (Glob), і запуск каже «ще не отримано»;
- **щоразу йде в мережу.** 3 виклики дали 3 GET;
- **межі ті самі:** `sud/velykyi` («понад 1000000 байтів»), `pereadresatsiia` (301), `lfs`, `obirvano` — код 1;
- **з `--з-теки` відмова:** «--звірити питає джерело власника (мережу); з --з-теки — не звірка адреси»;
- **вкладені звіряє теж.** Хеш дитини бере з байтів батька за sha256, тобто саме того, що виконається.

**Мережа.** Журнал за сесію — лише GET від моїх `--отримати`/`--звірити`. Від запусків, `--печатка`, `--розбір`,
`--перевірити-слід`, `-e` запитів немає.

**Підробка текстів (тримає).** `н2_смерть_підробка`: програма сама пише `☠ 「☠ модуля (слова автора модуля) «github.com/nigredo/…»: …」`.
- Виходить `✗ 3:1 ☠ модуля …`. У справжнього ☠ модуля префікс `адреса#sha256=…:2:28`.
- `--перевірити-слід` для підробки модулів не показує взагалі.
- Текст модуля йде лише з префіксом його адреси, переноси — `↵`, тож рядка програми модуль не підробить.
- `☠` λ програми, викликаної модулем, дає `✗ 3:24 μ …`, без «модуля».

**Дрібне (на тексти; дір немає):**
- **Н-1.** `--звірити` для програми без модулів з мережі (`к_г_сума_лок`, `н2_смерть_підробка`, двійник `атака30_6`)
  друкує «✓ --звірити: джерело власника віддає той самий вміст — 0 файл(и), sha256 збігся з закріпленим», хоча нічого не
  звіряли. Це той самий клас, що «✓ без запиту» суду 10, лише без шкоди: «0 файл(и)» видно, у двійника далі йде ⚠
  «ЛОКАЛЬНИЙ». Краще писати «модулів з мережі немає — звіряти нічого».
- **Н-2.** Перехопити «заборонено» може `☂` модуля (`спершу`) — тоді текст цієї помилки належить інтерпретатору. Але
  `--перевірити-слід` подає його як «текст — слова автора модуля, не інтерпретатора». Помилка в бік недовіри, бо
  «заборонено: 2» рахується окремо.
- **Н-3.** Неперехоплений `☠` модуля: у події сліду «помилка» поля `модуль` немає, є лише префікс у тексті. Перехоплений
  `☠` це поле має. `--перевірити-слід` пише лише «(помилка)». Бажано мати поле й рядок «☠ модуля 「адреса」».
- **Н-4.** `--отримати атака30_12_аргументи.ngr`: модуль у сховищі є, але нових правил не проходить (старий `kasa` з `⌂`).
  Вивід — «✓ … у сховищі (0 отримано, 0 уже було)», і лише нижче ⚠ «є й інші помилки до запуску». Це перехідний випадок
  (сховище суду 10), заголовок «✓» тут збиває.
- `--перевірити-слід --json` для двійника адреси дає `"з_мережі": false`, але людського ⚠ у JSON немає (ключа
  «попередження» там немає). Машині досить і `з_мережі`.
