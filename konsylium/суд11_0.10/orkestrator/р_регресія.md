## Дивне чи змінене (не регресія)

- **Д-1. Нативного Атанора не перевірити.** За непорожнього «для_авторів» Атанор не виконує сам **нічого**, навіть
  програму без модулів і підпису:
  ```
  $ ATHANOR_NO_FALLBACK=1 ngr р0_проста.ngr
  атанор: не виконую сам (для_авторів — еталон)
  $ ATHANOR_WHY=1 ngr р0_проста.ngr
  атанор → еталон: для_авторів — еталон
  3
  ```
  Так і заявлено (ПРАВИЛА, 6.3). Але на 0.9 (10б) `н3_кола_контроль`, `у8_місце_лок`, атаки SQLite й `схвалена.ngr` Атанор
  виконував нативно. Тепер для кожного власника, що вписав хоч один ключ автора, `ngr` = еталон. Тому таблиця вище
  порівнює еталон з еталоном. «Атанор = еталон» на цих атаках у конфігурації суду підтвердити запуском неможливо.
- **Д-2. `--перевірити-слід` мовчить про замок ОС.** Текст і `--json` не згадують подію «ізоляція» (ні «закрито», ні
  `seccomp`). Щоб дізнатися, що закрило ядро, оркестраторові треба шукати по сліду самому:
  ```
  $ ngr --перевірити-слід р0_url_слід.jsonl р0_огляд_url.ngr
  ✓ слід цілий і завершений (кінець): 8 записів; …
    виконавець: еталон (…)  тека …  аргументи [...]  спроб поза правами немає
  $ grep -o '"подія": "ізоляція"[^}]*' р0_url_слід.jsonl
  "подія": "ізоляція", "глибина": 0, "ядро": "seccomp", "закрито": ["процеси", "запис"], …
  ```
  Це прогалина нового, а не регресія. Про ізоляцію `--перевірити-слід --json` (`р0_кв_пс.json`) теж мовчить.
- **Д-3. Мітку `☠` модуля змінено** (після 10б, мабуть в огляді 10в): «☠ модуля (слова автора модуля)» → «☠ у коді модуля
  (текст міг прийти з переданих йому значень)». Подія «помилка» тепер має `модуль` і `текст_від`, а підробка
  (`н2_підробка`) — ні. Підробка далі друкує стару мітку, але тепер вона не збігається зі справжньою. Це краще.
- **Д-4. Порядок GET у `--звірити` для вкладених** (`к_б`): журнал — `main.ngr`, потім `util/dop.ngr`. У 10б було «спершу
  діти». Вердикт той самий (код ≠ 0, правильна адреса дитини, «модуль «…/main.ngr» закріпив»).
- **Д-5. `к_а_лічба`: 4/1 замість 5/3** — інші дані суду. Перелічив руками, вивід правильний.
