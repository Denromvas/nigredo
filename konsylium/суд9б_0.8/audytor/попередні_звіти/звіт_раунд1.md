## 1. Хеші

`sha256sum` поза текою пісочниця не пускає, тож брав поле `sha256` запису «початок» (`ngr ФАЙЛ --слід -`).
`nigredo.py 6b4066c1…fd95e`, `ngr.py 26dfc151…b2f9`, `двійники.tsv 78dfc857…9e51` і `nigredo_mcp.py 9f4ac981…e1bc5`
збігаються з ПРАВИЛАМИ. Поле «інтерпретатор» у сліді Атанора — `атанор:db4bbc5e…cfd91`, теж збігається. Це sha256
**джерел** (`SOURCE_SHA`), а не бінарника. Сам бінарник `athanor` не прочитати ні `sha256sum`, ні `<`, ні через `--слід`
(не UTF-8), тож його `00e3db2d…` **не перевірив**.

## 5. Ч — чесність заяв

- **«same output and the same signed trace» (README), «той самий вивід, ті самі помилки… той самий слід»
  (`athanor/README.md`)** — **не скрізь**. Знайшов 4 розбіжності: `⇣` кінцевої сигми, динамічний `\N{…}`, текст
  помилки `δ`, точка зупинки на `--слід-розмір`. Кожна вузька, але перша — неправильний вивід на звичайних даних.
- **«~4900, 0 differences» / «4916 програм — розбіжностей 0»**: як вимір на програмах репо — правдоподібно, і моя
  регресія (48) це підтверджує. `звірка.py` запускати не дозволено. Але цифра звучить як загальна гарантія, а
  ~700 моїх цільових порівнянь дали 4 розбіжності.
- **«Межі (`--кроки`, `--розмір`, глибина) — ті самі, і рахуються так само»** — для цих трьох ✓. `--слід-розмір`
  рахується інакше (+13 байтів).
- **Швидкість.** Методика чесна: процесорний час, найкращий з 11, по черзі, запуск інтерпретатора враховано й
  розкрито. Мій замір К4 — Атанор у 12 разів швидший за еталон. Але формулювання «faster than CPython both on agent
  tasks and on large data» ширше за виміряне:
  - 12 задач М6 — це 0,05–0,09 с у Python, тобто перевага переважно в запуску (≈6 мс проти ≈26 мс).
  - «Великі дані» — 0,04–0,11 с у Python, а більші Nigredo не бере (`… 1 2000000` — «значення завелике»).
  - `арифм` — рівно той шаблон `‰ × i i 7`, під який у README описано окремий швидкий шлях. Той самий підсумок з `¿`
    у тілі — 0,17–0,18 с процесорного часу проти 0,033 с на бенчмарковому записі, а README сам дає для Python
    0,042 с.
  - Python сам **не міряв**: пісочниця не пускає `python3 bench/…`.
- Дрібне: MCP-докстрінг (еталон замість Атанора); у сліді й `--help` — «версія 0.7».
