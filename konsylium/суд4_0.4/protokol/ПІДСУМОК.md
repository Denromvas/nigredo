# Четвертий суд: Nigredo 0.4 → 0.4.1 → 0.4.2 — підсумок

**Дата:** 2026-10-09/10. **Питання:** чи стає Nigredo спільною мовою агентів для програм, які агенти передають
одне одному / виконують від імені власника. **Вимога власника** (не голосувалась): мова — чорний ящик для людей.
**Склад:** Скептик, Практик, Мовознавець, Аудитор, Новачок (**лише через MCP**), Оркестратор — окремі сесії Claude;
Gemini (`gemini-3.8-flash` у раунді 1 спершу — денна квота вичерпана, далі `gemini-3.7-flash`).
**Завдання:** А–Г; Д — атаки суду 3 на 0.4 і нові; Е — шість чужих програм до запуску; Ж — доручення для іншого агента
(у раунді 2 кожен вирішував, чи запустив би чужі, лише за печаткою й розбором).

## Головні факти

- Усі розвʼязки (28) і доручення (7) правильні — перевірено секретарем.
- **Новачок, що бачив мову вперше і лише через MCP, розвʼязав усе з першої спроби.**
- Жодна атака суду 3 не спрацювала на 0.4. Межа «печатка → інструменти → файли» витримала всі атаки
  раунду 1; у 0.4.1 межу ослаблено регресією (`narrower`: «..» → «../../..» як «підтека») — знайшов Аудитор.
- Е: для `.ngr` рішення «запускати» — секунди за печаткою; `е3.py` з чесною печаткою знову тягнувся до чужого.

## Що виправлено

**0.4.1 (між раундами, за знахідками раунду 1):** неявні потоки (памʼять/жереб/файли в невиконаній гілці),
`±` і поріг `⚗`, помилки інструментів і типів; логічний розмір, межа цілих і сумарного обсягу; слід — канонічні
записи, час і запуск, привʼязка до програми, слід для відмови розбору, межа розміру, «виклик» до дії; `для_тек` не
для програм у теці запису, `-e` лише з `--тека`; вужчі права субагента; MCP — тека, шлях сліду, stdin.

**0.4.2 (після раунду 2):** Н1 — субагент звужує лише вглиб без «..», і печатку **кожного** субагента звіряють з
дозволами власника та з батьком за справжніми шляхами (негативні тести 39, 40); Н2 — функція, передана значенням
(не λ), вважається такою, що може змінити памʼять і світ (41); годинник `🜔час` не впевненіший за найсумнівніше
рішення (42); цілі в логічному розмірі, `»` перевіряє розмір; створення значень коштує кроків; глибока вкладеність —
звичайна помилка; повідомлення програми в stderr — через `safe()`, шлях сліду для MCP — окремим файлом, MCP-перевірка
сліду звіряє програму; слід старого формату — «⚠»; невидимі комбіновані знаки в іменах заборонено (43);
памʼятка описує все це чесно. Тести: 60 перевірок.

## Умови, що лишаються (Аудитор, для переходу Б → А)

1–3 закрито в 0.4.2 (з тестами). 4: «будь-яка зміна межі — лише з негативними тестами» — прийнято як правило;
**ще один раунд суду на замороженій версії**, у якому ніхто не пробʼє межу печатки. 5: окремі права для кожного
MCP-клієнта — відкрито.
