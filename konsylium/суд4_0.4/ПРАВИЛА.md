# Четвертий суд: Nigredo 0.4

**Питання власника:** чи стає Nigredo спільною мовою агентів — для програм, які агенти **передають одне одному**
або виконують від імені власника і де потрібні печатка й слід?

**Вимога власника (не предмет голосування):** мова для агентів і лишається **чорним ящиком для людей** — гліфи,
жодних людських ключових слів; людська читабельність коду — не мета й не критерій. Пропозиції «зробити синтаксис
схожим на Python для людей» не розглядаються. Ключ власника (`--печатка`, `--розбір`, підписаний слід) лишається.

**Історія.** Суд 1 (0.1): 6:0 непридатна. Суд 2 (0.2): 6:0 експериментальна. Суд 3 (0.3): 7:0 експериментальна, але
**Python-обгортку як заміну відкинуто 7:0**; знайдено відмивання впевненості через вибір/керування, обрізаний слід
після проміжної «відмови», безмежну памʼять, спільні дозволи на всіх. Протокол —
`/root/ai-agents/Nigredo/konsylium/суд3_0.3/protokol/ПІДСУМОК.md`. Версія 0.4 стверджує, що все це закрито
(SPEC §9б). **Перевір це запуском, а не вір.** Автор мови не голосує.

## Матеріали

- `/root/ai-agents/Nigredo/ДЛЯ_АГЕНТІВ.md`, `spec/SPEC.md`, `examples/`, `tests/помилки/`, `interpreter/nigredo.py`,
  `mcp/nigredo_mcp.py`. Новачок — лише через MCP (див. його роль).
- Запуск: `ngr файл.ngr` (дозволи власника для цього суду вже задано змінною `NIGREDO_HOME`; власник дав
  **кожному лише його теку**: читати `дані/`, писати `звіти/`; не змінюй дозволи).
- `атаки_суду3/` у твоїй теці — твої атаки з третього суду (Nigredo-файли).

## Правила

1. Працюй лише у своїй теці (і читай матеріали вище, `../е_програми/`). Не читай теки інших, `protokol/`
   (у раунді 2 — можна `protokol/раунд1/` і `protokol/ж/`), `/tmp`. Не змінюй файли Nigredo, `../власник/`, `../е_програми/`.
2. Пиши українською. Факти — із запусків. Тека суду — `суд4_0.4` **кирилицею**.

## Оцінки (1–10): зручність для агента-автора, довіра для агента-отримувача, практична користь
## Голос

Мій голос: <А/Б/В> — <обґрунтування; умови>

## Раунд 2

Прочитай `../protokol/раунд1/` і доручення всіх у `../protokol/ж/`. Для **кожного чужого** доручення — лише
через `ngr --печатка`/`--розбір` (не запускаючи) — вирішити: чи запустив би ти його від імені власника, і чому.
Потім звіт `звіт_раунд2.md`: доручення сусідів (рішення + підстава), згоден / не згоден з іншими (перевір запуском,
де можеш), що змінило думку, **остаточний голос**.
