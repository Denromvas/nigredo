## 4. П — проти еталона за читанням

Порівняння логіки перевірки прав у `albedo/хост.mjs` та `athanor/src/seal.rs`:

1. **Розбіжність визначення робочої теки для секції `для_тек`:**
   - **Еталон (`athanor/src/seal.rs:163-164`):**
     ```rust
     if let Some(c) = cwd {
         if dd.starts_with('/') && pathx::inside(c, &dd) {
     ```
     Еталон перевіряє потрапляння **поточної робочої теки виклику (`cwd`)** у дозволену теку.
   - **Господар Альбедо (`albedo/хост.mjs:125`):**
     ```javascript
     for (const [d, extra] of perDir) {
       const e = expand(d);
       if (e.startsWith('/') && inside(progDir, real(e)) && !selfWritten) allowed.push(...extra.map(canon));
     }
     ```
     Господар перевіряє **теку розташування самої програми (`progDir`)**, повністю ігноруючи `process.cwd()`.
   - **Наслідок для звичайної програми:**
     Якщо у `дозволи.json` є правило `для_тек: { "/проекти/тест": ["час"] }`:
     - При запуску програми `/інше/скрипт.ngr` перебуваючи в терміналі в `/проекти/тест`:
       - `ngr` (еталон/Атанор): дозвіл `час` **надається** (бо `cwd == "/проекти/тест"`).
       - `хост.mjs` (Альбедо): дозвіл **блокується** (код 3), бо `progDir == "/інше"`.
     - І навпаки: запуск скрипту, розташованого в `/проекти/тест/скрипт.ngr`, із каталогу `/tmp`:
       - `ngr`: відмова у правах.
       - Альбедо: права надаються.

2. **Перевірка дозволів для інструментів типу `команда` (`процес`):**
   - **Еталон (`athanor/src/seal.rs:231-232`):**
     ```rust
     } else if kind == "команда" {
         ok = ok || cmd_within(s, gr);
     ```
     Використовує структурне зіставлення префіксів команд `cmd_within`.
   - **Господар Альбедо (`albedo/хост.mjs:137`):**
     ```javascript
     return !gs.some((g) => g.scope && (kind === 'тека' ? expand(g.scope).startsWith('/') && inside(scopeOf(w.scope), real(expand(g.scope))) : g.scope === w.scope));
     ```
     Для всіх типів, крім теки, виконується строго строкове порівняння `g.scope === w.scope`.
   - **Наслідок:** якщо власник дозволив префікс команди, на етапі перевірки печатки господар Альбедо відмовить програмі кодом 3 через відсутність точного збігу рядка.

3. **Обробка запиту інструменту без вказання області (`scope`):**
   - **Господар Альбедо (`albedo/хост.mjs:134`):**
     `if (!w.scope) return false;`
     Якщо програма запитує загальний інструмент без параметрів, `lacks` одразу повертає `false` за наявності хоча б одного запису відповідного інструменту у власника, не перевіряючи, чи цей запис обмежував область дії.
