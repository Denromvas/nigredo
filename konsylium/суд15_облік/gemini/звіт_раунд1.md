2. **Результат `🜁` (субагент):** показ поверненого результату в сліді тепер списує кроки за логічний розмір `res.n` (`interp.rs:1928`, `nigredo.py:7121`).
3. **Рішення `⚗` (відсів за порогом):** показ кожного елемента в сліді списує кроки за суму розмірів усіх елементів списку (`prims.rs:504`, `nigredo.py:7560`: `work(sum(x.n))`).
4. **Аргументи інструмента (`🜔`):** `tool_begin` тепер стягує кроки за сумарний логічний розмір аргументів (`interp.rs:1527`, `nigredo.py:6374`: `work(sum(a.n))`).

6. **Глибока копія `capc`:**
   - при виклику функції зі зниженою впевненістю (`►`, `call`): списується повний розмір копії результату (`interp.rs:921`, `nigredo.py:6800`);

#### Б. Аналіз здешевлення (чи не відкрились нові діри)
1. **`► ▶ ✓ 🜍` та `§` коштують 1 (`interp.rs:298`, `nigredo.py:6685`):**
   - Якщо значення повертається без зміни впевненості, воно вже існує в пам'яті. Виділення нової пам'яті не відбувається (в Rust — клонування `Arc`/вказівника, в Python — копіювання посилання).
   - Для рядків `§`: повернення символу або зрізу не клонує піддерево даних. Якщо ж у `§` відбувається зниження впевненості, спрацьовує прапорець `self.fresh` (`interp.rs:317`, `nigredo.py:6683`), який списує повну ціну `res.n`.
2. **`μ φ ⇅ ⚗ ↺ ⊞` сплачують лише власні елементи (`own + 1`):**
   - Для `μ`, `φ`, `↺`, `⇅`: новий контейнер виділяє буфер лише під свій вектор посилань (`len + 1`). Елементи всередині або вже були оплачені раніше, або оплачуються операціями всередині лямбди/обчислення.
   - Подвійний облік усунуто: раніше `μ` змушував повторно сплачувати за весь логічний розмір раніше створених структур.
   - Приховати гігантську структуру неможливо: інваріант `res.n > self.max_size` перевіряється в `sized_as` / `sized` для абсолютно будь-якого створюваного значення незалежно від `spent`.
3. **`⊞` (групування):**
   - `spent` рахує кількість груп (`own`) + суму довжин списків у кожній групі + 1 (`interp.rs:309`, `nigredo.py:6692`). Це точно відображає обсяг щойно виділеної векторної пам'яті.

#### В. Що залишилось поза лічильником «створено»
- **Шаблон `〔〕`:** платить кроки за свій розмір, але створення рядка обмежено загальним лімітом `--розмір` (до 5 млн) через `sized`.
- **`»` (вивід):** не бере кроків за обхід, але жорстко обмежений межею розміру сліду (`--слід-розмір`, 50 МБ) та стеком глибини.
- **Дії інструментів:** контролюються відповідними квотами (`Caps`), а не абстрактними кроками памʼяті.
