## Вади 0.1 — чи виправлено?

1. **Межа делегування проникна — частково, і з’явилась нова діра.** Імена батька змінити справді
   неможливо (значення незмінні). Але **субагент виконує інструменти поза своїми дозволами через
   функцію батька**: `проби/3_делегування.ngr` — субагент «обмежений» з печаткою `【「жереб」】`
   викликає `спитати` (λ батька з `🜔оракул`) — оракул відпрацював; у сліді запис №4:
   `"агент": "головний/обмежений", "назва": "оракул"`, хоча №3 щойно записав йому `"дозволи": {"жереб": []}`.
   Для інструментів з обмеженням (`файл.писати`) запис не відбувся, але **інтерпретатор упав із
   Python-трасою `KeyError: 'файл.писати'`** (`проби/4_…`), `☂` цього не перехоплює (`проби/5_…`).
   Перевірка «🜔 лише з печатки найближчого агента» — лексична; під час виконання для `оракул/жереб/час`
   її немає зовсім, для решти — є лише як аварія (`ngr`, `_path_ok`, `it.caps[tool]`).
   `--печатка` при цьому показує «субагент «читач»: дозволи: оракул» — власника це вводить в оману.
2. **Слід можна підробити — частково.** Програма в слід писати не може, JSON-екранування є — це виправлено.
   Але ланцюжок — **SHA-256 без ключа** над `json.dumps(sort_keys=True)` (`ngr`, рядки 543–563): хто має
   доступ до файлу, змінює запис і перераховує всі хеші — `--перевірити-слід` скаже «✓». Скрипт підробки
   написав (`проби/підробити_слід.py`), **запустити не зміг — Python у цій сесії не дозволено**, тож це
   висновок із коду, не з запуску. З запуску інше: **обрізаний слід проходить перевірку** —
   `проби/слід5.jsonl` (3 записи, без `помилка` і `кінець`) → `✓ слід цілий: 3 записів`.
3. **Слід неповний / суперечить дійсності — частково.** `⚗` справді пише кожне рішення «лишено/відкинуто»
   (слід_В, №18–22) — виправлено. Але: при аварії (п.1) слід обривається без запису про помилку;
   і слід фіксує дію субагента поза його дозволами без жодної позначки «порушення».
4. **Впевненість відмивається — частково.** `＝ x x` → 0.3 (мінімум, не добуток) і `¿` — виправлено.
   Але `проби/1_впевненість.ngr`, `x = ≈「а」 0.3`: `± ⁀【x x】「 」` → **1**; `± §✂x「 」 0` → **1**;
   `± §δΔ【x】 0` → **1**; `± §κ ✎『』 x 1 0` → **1**; `φ` і `↻` з умовою від оракула (0.46) → результат **1**.
   Без `≈` і без запису в слід. Реалістичний випадок (`проби/2_…`): відповіді оракула 0.46 і 0.44 →
   `μ` → `⁀` у звіт → `± звіт` = **1**, і звіт проходить `⚗ … 0.9`. Саме так агент і складав би звіт.
   Твердження SPEC §1 «її не відмити» вірне лише для `¿`.
5. **Тихі збої — частково.** Зайве в рядку — справді помилка. Але **пропущений аргумент мовчки
   «зʼїдає» наступний рядок** (правило продовження): `← ціна × 2` / `ρ「абв」` / `» ціна` → друкує `6`,
   код 0, жодного попередження. `» ＋ 1 ¦ » 2` — спершу друкує `2`, потім падає з «очікувалося число,
   а не ніщо» — під час виконання, а не «до запуску», як обіцяє SPEC §1.
6. **Лексичні пастки — здебільшого так.** `+` → «невідомий символ «+» — може, ＋?»; рядок+число — зрозуміла
   помилка. Залишок: `＋ 1٢ 3` → `15` (цифри різних письмен в одному числі мовчки склеюються). Дрібниця.
7. **Памʼятка без сигнатур — так.** Сигнатури, приклади, розділ «Пастки» є.
8. **`--розбір` — глосарій — так.** Тепер справжній переклад: «опл ← ті z з зам, де z[«оплачено»]».
   Найкраще виправлення у 0.2.
9. **Немає ліміту кроків — так.** `↻ 0 λs ● λs s` → `✗ перевищено ліміт кроків`, `☂` не перехоплює.

Умови консиліуму до 0.1: оголошення з `~/.claude/CLAUDE.md` **не прибрано**, лише додано «на розгляді,
для реальної роботи — після вердикту» (частково). Порівняння з Python-бібліотекою «слід+впевненість+печатка»
в матеріалах не бачу — не знаю, чи робилось.

## Нові вади 0.2

   Мова, що продає українські імена, сортує українську неправильно. Завдання Г пройшло лише тому, що
   к/м/х випадково в базовому діапазоні.
4. **Агентні можливості — переважно декорація**: `оракул` — імітація з хешу; «субагент» — той самий процес;

   (записав і одразу прочитав). Справжні лише файли, `мережа.взяти` (лише GET) і `агент` (`claude -p`).
5. **Немає аргументів програми** (SPEC §8): параметризувати програму нічим — кожне завдання = новий файл.

## Оцінки (1–10)

- Зрозумілість для ШІ-агента: **7** — Б і Г з першої спроби без прикладів; але правило продовження рядка — пастка.
- Виразність: **6** — словники/JSON/файли є, Г вкладається в 9 рядків; групування незграбне, немає аргументів, процесів, POST.
- Практична користь для реальної роботи агентів: **3** — та сама задача Г у Python — стільки ж рядків, і Python агент уже знає; цінність лише в печатці/сліді, а вони мають діри.
- Прозорість для людини-власника: **6** — `--печатка` і `--розбір` справді добрі; але печатка субагента й слід можуть вводити в оману (п.1–2).

## Сильні сторони

1. Префіксний запис із фіксованою арністю + `--розбір` як справжній переклад: програму можна прочитати.
2. Печатка, звірена з `дозволи.json` власника, і `realpath`-перевірка шляхів (`../дані/../дозволи.json` відхилено).
3. Якісні повідомлення про помилки з підказками (`+` → `＋`, рядок+число → `σ`) і ліміт кроків.

## Слабкі сторони

1. Головні гарантії — межа `🜁`, недоторканність сліду, невідмивна впевненість, «жодних тихих збоїв» —
   кожна має відтворюваний контрприклад (див. вище).
2. Цінність — у середовищі виконання (дозволи, слід), а не в мові; гліфи лише додають бар’єр (і в памʼятці ж
   визнано: кириличні імена в 3–8 разів дорожчі в токенах).
3. Агентна частина здебільшого імітація; «памʼять» і «субагент» не мають реального змісту.

## Пропозиції

1. Перевіряти дозвіл **кожного** `🜔` під час виконання за `caps` поточного агента (замикання не несе прав батька
   або несе явно, із записом у слід); відмова — нормальна `✗`, не `KeyError`.
2. Слід: запис `кінець` обовʼязковий для «✓»; HMAC/підпис ключем власника або зовнішній якір останнього хешу.
3. Впевненість агрегатів (`⁀ ✂ δ Δ κ ρ`) = мінімум по елементах; `φ`/`↻` успадковують впевненість умов, як `¿`.
4. Незавершений вираз у кінці рядка — помилка розбору (або явний знак продовження); `↑` за українською колацією.
5. Нарешті зробити те, що просив минулий консиліум: «печатка + слід + впевненість» як Python-бібліотека/обгортка,
   і порівняти чесно на тих самих чотирьох завданнях.

Процедурне: через описку в шляху (латинські «su» замість «су») я випадково створив поза своєю текою
три порожні/однорядкові файли в `/root/ai-agents/Nigredo/konsylium/suд2_0.2/skeptyk/` (`x`, `проби/placeholder`,
`проби/8_тихий.ngr`). Нічого не читав і не змінював чужого; видалити їх мені не дозволено — прошу секретаря прибрати.
