# Повторний огляд (суд 8б): що перевірити

Сервер: `http://127.0.0.1:28709` (`GET /ціна/ТОВАР` — ціна за 0,4 с; `/повільно/N`; `POST` — відлуння тіла).
Задачі суду 8 (К1–К4) — у `ЗАВДАННЯ_суду8.md` (порт уже 28709); твої розвʼязки — у твоїй теці.

Що змінилося (SPEC §9в «0.7-dev, після суду 8»; памʼятка — `ngr --памʼятка`):
- `χ`-запис: назви — лише XML Name, керівні символи — помилка; розбір на expat (DTD забороняє розбирач); атрибути з
  різних просторів — помилка. `↘`: замкнена граматика, вузли без повторів у порядку документа (за позицією), `[n]`
  як у XPath, `//X` бачить корінь, `//@атр`, кроки за вузли, ручний вузол — помилка програми.
- Квоти: модуля — на весь запуск; субагента — на кожен запуск; невиконані виклики (відмова за правами, скасування в
  `‖`) квоту не списують; «квоту вичерпано» — окрема подія; дві квоти, `≤0`, не-ASCII цифри — помилка до запуску;
  `--дозволи` лишає квоти власника й приймає `≤N`; квоти в `--печатка` (субагенти, модулі) і `--розбір`.
- `--тести`: кожен тест — окремий процес (свій слід, ліміт 300 с); лічба `🜍` зі сліду; перехоплений провал,
  0 перевірок, сумнівна — не «пройшов»; тести з тек запису не беруться; печатки тестів у підсумку.
- Вкладеність виразу > 1000 — помилка до запуску (код 2). `--сухо`: `час`, `оракул` після придушеної дії — невідомі.
- `✓`: кроки, `「…」 S`, межі (навпаки, нескінченні, не для типу — помилка схеми; `¯`), `「дата」` без часу.
- `ν` лише 0–9; `⌗` без «-0.00»; SQLite `load_extension` — відмова одразу; `ϵ` — підказка; давнє значення після
  «могло впасти» — не впевненіше. Підказка арності в помилках розбору.
- Мірило: README — М2 «до» і «після» на тому самому наборі; М3 0,88× (36 пар); `bench/великі/міряти.py`.
