# Суд 8в: що змінилося після суду 8б

Сервер: `http://127.0.0.1:28709` (`GET /ціна/ТОВАР` — ціна за 0,4 с; `/повільно/N`; `POST` — відлуння тіла).
Що було перед 8б — `ЗАВДАННЯ_суду8б.md`; задачі суду 8 — `ЗАВДАННЯ_суду8.md`. Памʼятка — `ngr --памʼятка`.

Зміни після 8б (SPEC §9в «0.7-dev, після суду 8б»):
- Квоти не ховають «заборонено»: при вичерпаній квоті спершу права виклику (перевірка без дії) — поза ними «заборонено».
  `--повторити` повертає квоту за відмову, як справжній запуск.
- SQLite: «заборонено» — лише коли відмовив authorizer (права перевіряються на `EXPLAIN` запиту), не за текстом
  помилки; `VACUUM` — відмова за першим словом; `load_extension` — «заборонено», а в значенні — не тривога.
- `--дозволи` не вимикає «код із теки запису — не модуль»: теки запису — з дозволів власника до звуження.
- Глибокі значення (`δ` > 1000, `〔{…}〕`, аргумент інструмента, результат субагента) — помилка програми, `☂` ловить.
- `↘`: `]` у лапках умови — частина значення; `[n]` — лише 0–9; префікс у шляху — помилка.
- `✓`: рядок схеми розбирається раз; межі й переліки — цифри 0–9 (`¯`), перелік чисел — за значенням; порожні межі,
  порожня альтернатива, межі для `∅` — помилка схеми.
- `--сухо`: `час` і `оракул` невідомі завжди. `χ`-запис: лише назви, які розбирач прочитає назад; невідомі ключі —
  помилка; `\r` — `&#13;`. `--печатка`: квоти власника. `ngr --тести --печатка` — печатки тестів без запуску.
  `--тести`: `перехоплено_помилок`. MCP: тайм-аут вбиває групу процесів; `nigredo_testy` з `pechatka`.
- Мірило: README — М3 із застереженнями; великі дані — збережений прогін.
