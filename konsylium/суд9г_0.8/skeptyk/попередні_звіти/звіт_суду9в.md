## 3. Н — нове на виправленнях (`атака13_*`)

### Н-1. Випадковий rowid без «жереб» — власний BEFORE-тригер спрацьовує ПІСЛЯ перевірки Nigredo (обидва)

Перевірка суду 9б — тимчасовий тригер `BEFORE INSERT … WHEN (SELECT max(rowid)…) = 2⁶³−1` (`nigredo.py:3304–3307`). Але
SQLite запускає TEMP-тригери першими, а rowid вставки рахує (OP_NewRowid) уже після ВСІХ BEFORE-тригерів. Отже
власний тригер програми встигає поставити рядок із 2⁶³−1 уже після того, як перевірка пройшла.
`атака13_бд_тригер.ngr`, печатка — лише `「бд.писати:звіти」`:
```
CREATE TRIGGER пастка BEFORE INSERT ON t WHEN NEW.x = 1
  BEGIN INSERT OR IGNORE INTO t(rowid, x) VALUES (9223372036854775807, 0); END
INSERT INTO t(x) VALUES (1)          ← rowid навмання
```
Вивід «випадкове 0–99 з rowid SQLite (без права «жереб»)»: Атанор — 83, 78, 97, 10; еталон — 36, 31, 21, 23.
`--перевірити-слід` обох — ✓, «спроб поза правами немає». `--сухо` чесний (7 дій не виконано), `--повторити` ✓.
Межу дій це не пробиває. Але рядок памʼятки «без 「жереб」 запис у таблицю з rowid 2⁶³−1 — відмова» неправдивий, і
квоту `жереб≤N` так само обійдено. Це та сама знахідка суду 9б, лише через двері поруч.
**Виправлення:** додати TEMP-тригери `AFTER INSERT` і `AFTER UPDATE … WHEN NEW.rowid = 9223372036854775807` — відмова
(без «жереб» жоден рядок не дійде до 2⁶³−1); BEFORE лишити для старих файлів. Тест — `атака13_бд_тригер`.

### Н-2. Квота `час≤N` не діє на годинник SQLite (обидва) — непослідовно з `жереб≤N`

`атака13_квота_час.ngr` (`「час≤1」 「бд.читати:дані」`): `🜔час` — один раз, далі «вичерпано квоту», а
`strftime(…, 'now')` у SQLite тричі дає час. Для порівняння, `атака13_квота_жереб` з `「жереб≤1」`: `random()` —
«заборонено… (з квотою «жереб≤N» — лише 🜔жереб)». У коді `_db_rights` (`nigredo.py:3219`) «час» перевіряють без
квоти. Слід ✓ «квоту вичерпано: 1». Це менше за Н-1: квота — межа «викликів», і SQLite формально не `🜔час`. Але
оголошена межа годинника не тримає, і для жеребу суд 9б саме це назвав вадою. **Виправлення:** «час» з квотою — як
«жереб» з квотою (годинник SQLite — відмова) або рядок у памʼятці.
