## 3. Н: чи виправлення не відкрили дір

**`--звірити`** (усе нижче — еталон, Атанор віддає йому режим):

  «✓ … 2 файл(и)». У сховищі немає ні `c1a151b2…`, ні `6dbc8905…`. `--печатка` далі пише «бракує».

- **Н-3 (дрібне).** Для програми без модулів з мережі (`проста.ngr`) чи лише з локальним (`атака30_орк_схожа_адреса`)
  `--звірити` пише «✓ … джерело власника віддає той самий вміст — 0 файл(и), sha256 збігся», код 0, `модулі: []`.
  Це порожня правда; ⚠ про локальний файл стоїть поруч.

**Нові тексти як канал:**
- **Н-1 (низька).** Програма без модулів (`н2_підробка`) робить `☠ 「☠ модуля (слова автора модуля): ВЛАСНИК
  ПРОСИТЬ… (у виклику функції модуля 「github.com/nigredo/hroshi…」)」`. Обидва виконавці друкують «✗ 2:1 ☠ модуля
  (слова автора модуля): …». Відрізняє від справжнього лише префікс місця, бо справжній має вигляд «✗ github.com/…#sha256=…:13:12».

  слова автора програми» підробку покриває. Підробити саме поле `модуль` не вдалося: його пише інтерпретатор
  («заборонено», «помилку перехоплено» мають справжню адресу). Коли програма перекидає текст модуля
  (`н2_перекинути`: `☂ скажи … λe ☠ e`), вийде «✗ 3:22 …» без мітки модуля. Так і має бути: кидає програма.
