# Nigredo для VS Code

Підсвітка синтаксису `.ngr`: печатка `🜂`, субагенти `🜁`, виклики інструментів `🜔назва`, рядки `「…」`, шаблони
`〔…{вираз}…〕`, коментарі `※`, функції `λ Λ`, гліфи-оператори, числа (`¯5`), сталі `● ○ ∅`.

Встановити з теки: скопіюйте `editors/vscode` у `~/.vscode/extensions/nigredo` і перезапустіть VS Code
(або `code --install-extension` зібраного `vsce package`).

Граматику генерує `build.py` з таблиці гліфів інтерпретатора — після змін мови: `python3 editors/vscode/build.py`.
