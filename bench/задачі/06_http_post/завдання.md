# Надіслати звіт POST-запитом

Перший аргумент програми — порт. Надішли POST на `http://127.0.0.1:ПОРТ/report` з JSON `{"сума": 42, "валюта": "грн"}`
(заголовок `Content-Type: application/json`). Сервер відповідає JSON `{"прийнято": true, "№": …, "отримано": …}`.
Надрукуй `прийнято №<№>, сума <отримано>`.
