# Відʼємні залишки на складі

`дані/склад.db` — SQLite: `товари(id INTEGER, назва TEXT)` і `рухи(товар_id INTEGER, тип TEXT, кількість INTEGER)`,
де `тип` — `прихід` або `видаток`. Залишок товару — сума приходів мінус сума видатків. Надрукуй товари з відʼємним
залишком за зростанням залишку (при рівності — за абеткою назви) рядками `назва: залишок`; потім рядок
`Нульових: N` — скільки товарів мають залишок рівно 0 (товари без жодного руху — теж нульові).
