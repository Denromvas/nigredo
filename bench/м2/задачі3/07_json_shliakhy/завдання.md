# Великі числа у вкладеному JSON

`дані/структура.json` — довільно вкладені обʼєкти й списки. Знайди всі числа більше 100 (будь-де) і надрукуй для
кожного рядок `шлях = значення` у порядку обходу документа (ключі обʼєкта — у порядку файлу). Шлях — ключі й індекси
списків через крапку, починаючи від кореня, наприклад `відділи.0.люди.1.ставка`. Останнім рядком — `Знайдено: N`.
