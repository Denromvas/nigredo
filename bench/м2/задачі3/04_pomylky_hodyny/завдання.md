# Помилки за годинами

`дані/app.log` — рядки виду `2026-10-18 09:41:07 [ERROR] api: текст`. Для кожної години, в якій є хоча б один
рядок рівня `ERROR`, надрукуй (за зростанням години) `ГГ:00 — N (модулі через кому за абеткою, без повторів)`,
а останнім рядком — `Найгірший модуль: імʼя (M)` — модуль із найбільшою кількістю `ERROR` за весь журнал (при
рівності — перший за абеткою).
