# Прострочені задачі

`дані/задачі.json` — список обʼєктів `{"задача", "відповідальний", "термін" (дата ISO), "виконано" (true/false)}`.
Сьогодні — `2026-10-20`. Прострочена — невиконана задача, термін якої раніше за сьогодні. Надрукуй прострочені за
спаданням днів прострочки (при рівності — за абеткою назви) рядками `задача (відповідальний): N дн.`, а останнім —
`Прострочено: K`.
