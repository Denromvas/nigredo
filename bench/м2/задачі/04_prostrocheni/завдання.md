# Прострочені рахунки

Файл `дані/рахунки.json` — список обʼєктів `{"номер", "дата", "днів_на_оплату", "сплачено"}`; дата — ISO
`2026-09-01`, сплачено — true/false. Сьогодні — 2026-10-15. Рахунок прострочено, якщо його не сплачено і
дата + днів_на_оплату раніше за сьогодні. Надрукуй по рядку `номер: N днів` (на скільки днів прострочено),
за спаданням N, а за рівного — за номером.
