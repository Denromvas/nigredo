# Помилки за годинами

Файл `дані/лог.txt`: кожен рядок — `ЧАС РІВЕНЬ повідомлення`, де ЧАС — ISO `2026-10-14T09:15:02`, РІВЕНЬ — `INFO`,
`WARN` або `ERROR`. Порахуй рядки з рівнем `ERROR` за годинами. Надрукуй по рядку `ГГ: кількість` (година двома
цифрами), за зростанням години; години без помилок не друкуй.
