# Адреси сторінок зі заголовків

Файл `дані/заголовки.txt`: по заголовку в рядку (латиниця). Для кожного непорожнього рядка зроби «slug»: малі
літери; кожна послідовність символів, що не є латинською літерою чи цифрою, — один дефіс; без дефісів на початку
й у кінці. Надрукуй slug-и по рядку в тому ж порядку.
