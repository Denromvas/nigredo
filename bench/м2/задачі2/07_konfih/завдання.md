# Успадкування налаштувань

`дані/конфіги.json` — словник `імʼя → {"успадковує": імʼя або null, "значення": {ключ: значення}}`. Підсумкові
значення конфігу — значення предка, перекриті власними (ланцюжок будь-якої довжини). Для кожного конфігу (за абеткою)
надрукуй `імʼя: ключ=значення, …` (ключі за абеткою; значення як у JSON, рядки — без лапок), або `імʼя: цикл`, якщо
ланцюжок успадкування зациклюється (зокрема через предка).
