# Оплати клієнтів за регіонами

`дані/база.db` — SQLite, таблиця `оплати(клієнт_id INTEGER, сума INTEGER, статус TEXT)`; `дані/клієнти.json` — словник
`"id" → {"імʼя", "регіон"}` (ключі — рядки). Рахуй лише оплати зі статусом `ок` клієнтів, які є в `клієнти.json`.
Надрукуй для кожного регіону (за спаданням суми, при рівності — за абеткою) рядок `регіон: сума (імена через кому за
абеткою)` — лише клієнти з хоча б однією врахованою оплатою.
