# Медіана за групами

`дані/виміри.csv` з заголовком `датчик,значення`; значення — десяткове число з крапкою або порожнє (пропуск — не
враховувати). Для кожного датчика — медіана його значень (парна кількість — середнє двох середніх, точно). Надрукуй
`датчик: медіана` (медіана — без зайвих нулів у кінці, напр. `2.5`, `3`, `0.15`), за абеткою датчика; датчик, у якого
немає жодного значення, — `датчик: —`.
