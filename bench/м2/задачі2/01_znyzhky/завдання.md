# Виручка за категоріями зі знижками

`дані/замовлення.json` — список замовлень `{"номер", "код", "позиції": [{"товар", "категорія", "ціна", "кількість"}]}`;
`код` може бути `null`. `дані/коди.json` — словник `код → знижка у відсотках` (ціле). Невідомий код — без знижки.
Знижка діє на кожну позицію замовлення. Виручка позиції = ціна × кількість × (100 − знижка) / 100, округлена до копійок
(половину — вгору) **для кожної позиції окремо**. Надрукуй `категорія: сума` (2 знаки) для кожної категорії, за спаданням
суми, при рівності — за абеткою.
