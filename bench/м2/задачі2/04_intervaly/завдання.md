# Злиття інтервалів

`дані/бронювання.csv` (`кімната,з,по`; дати ISO, обидві включно). Для кожної кімнати злий інтервали, що перетинаються
або стикаються (наступний починається наступного дня після кінця попереднього). Надрукуй для кожної кімнати (за
абеткою) рядок `кімната: з..по, з..по (N днів)`, інтервали за датою, N — загальна кількість зайнятих днів.
