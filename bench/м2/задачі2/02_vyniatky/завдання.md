# Винятки в журналі

`дані/журнал.txt`: записи починаються з часу `2026-10-14 09:15:02`; рядки, що починаються з пробілу, — продовження
попереднього запису. Запис-виняток — той, у якому є рядок продовження виду `  ТипВинятку: повідомлення` (останній такий
рядок запису — тип). Для кожного типу надрукуй `Тип: N (перший ЧАС, останній ЧАС)` — кількість записів із цим типом,
час першого й останнього; за спаданням N, при рівності — за абеткою типу.
