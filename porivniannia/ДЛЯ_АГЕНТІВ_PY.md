# ngrpy — памʼятка для агентів (Python-обгортка з гарантіями Nigredo)

Звичайний Python 3 + бібліотека `ngrpy`. Запуск: `python3 porivniannia/ngrpy.py скрипт.py [--дозволи F] [--слід F] [-- аргументи]`.

## Правила

- Скрипт: спершу імпорти, потім **печатка** — `seal("намір", ["дозвіл", …])` з буквальними рядками.
  Формат дозволів той самий, що в Nigredo: `「оракул」` → `"оракул"`, `"файл.читати:дані"`, `"мережа.взяти:хост"`, `"агент:імʼя"`.
- До запуску: печатка звіряється з дозволами власника (`~/.nigredo/дозволи.json`; `--дозволи` лише звужує),
  а кожен `tool(...)` у коді мусить мати **буквальну** назву з печатки.
- Під час виконання (`sys.addaudithook`): відкривати файли, мережу, процеси, `ctypes`, `gc`, `inspect`,
  `sys._getframe`, `settrace` тощо заборонено — лише через `tool(...)`. Читати стандартну бібліотеку можна.
- Слід — той самий, що в Nigredo: завжди, у `~/.nigredo/сліди/*-py.jsonl`, підписаний; `ngr --перевірити-слід`.

## API (`from ngrpy import *`)

| Виклик | Що робить |
|---|---|
| `seal(намір, [дозволи])` | печатка, перший вираз після імпортів |
| `tool(назва, *аргументи)` | інструмент (ті самі, що в Nigredo: `оракул`, `жереб`, `час`, `файл.читати`, `файл.писати`, `файл.список`, `мережа.взяти`, `агент`); повертає `U` |
| `with delegate(імʼя, намір, [дозволи]):` | субагент: підмножина дозволів батька, власна памʼять; інструменти всередині — з його правами |
| `remember(ключ, v)`, `recall(ключ)` | памʼять поточного агента (`None`, якщо нема) |
| `check(v, lambda x: …)` | перевірка; умова має дати `bool`; інакше виняток |
| `U(v, c)` | значення з впевненістю; `+ - * / % == < …` над `U` дають мінімум; `bool(U)` — помилка |
| `conf(x)` | впевненість (`U`, а для списків/словників — мінімум вмісту) |
| `value(x)` | зняти `U` (**впевненість губиться**) |
| `sift(список, поріг)` | лишити елементи з `conf ≥ поріг`; кожне рішення — у слід |
| `set_conf(x, c)` | явно змінити впевненість (у слід) |
| `print(...)` | друк (записується в слід) |
| `ARGS` | аргументи після `--` |

## Приклад

```python
from ngrpy import *
seal("спитати оракула через субагента і лишити впевнені відповіді", ["оракул"])

def ask(q):
    with delegate("провидець", "спитати оракула", ["оракул"]):
        return tool("оракул", q)

answers = [ask(q) for q in ["чи сіль тверда?", "чи сірка горить?", "чи світ чорніє?"]]
confident = sift(answers, 0.6)
remember("впевнені", confident)
check(recall("впевнені"), lambda x: len(x) == len(confident))
print(len(confident))
```

## Чесно про межі

- Python-документація прямо каже: audit hooks — **не пісочниця**. Впевненість живе лише в `U`:
  будь-яка звичайна операція Python над `value(x)` (`len`, `str`, f-рядок, `json.loads`) її губить.
- Статично перевіряються лише буквальні `tool("…")`; що ще зробить довільний Python-код — до запуску не відомо.
